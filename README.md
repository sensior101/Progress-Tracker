# Progress Tracker

프로젝트 진행 상황과 업무별 일정을 한눈에 관리하는 HTML 템플릿과 AI 스킬.

별도 빌드나 서버 없이 HTML 파일을 브라우저에서 열어 사용합니다. Claude Code 스킬로 프로젝트를 분석해 체크리스트를 채우거나, HTML 내부 JSON을 직접 수정할 수 있습니다.

## 주요 기능

- **진행 현황**: 전체 진행률, 완료·미완료 작업 수, 다음 할 일을 표시합니다.
- **프로젝트 보드**: 단계별 체크리스트, 메모, 접기와 전체·미완료·완료 필터를 제공합니다.
- **업무 캘린더**: 기존 업무를 특정 날짜에 등록하고 날짜별 업무를 확인합니다.
- **완료 상태 연동**: 보드와 캘린더 어디에서 체크해도 완료 상태와 진행률에 함께 반영됩니다.
- **브라우저 저장**: 체크 상태와 등록 날짜를 현재 브라우저에 저장합니다.
- **화면 구성**: Neo-brutalist 스타일, 밝은·어두운 테마 전환, 화면 크기에 따른 배치를 제공합니다.

## 파일 구성

```text
README.md
progress-tracker/
├── SKILL.md        # Claude Code의 페이지 생성·갱신 규칙
└── template.html   # 디자인, 프로젝트 데이터, 체크리스트, 캘린더를 포함한 단일 HTML
```

## 바로 사용하기

1. `progress-tracker/template.html`을 사용할 프로젝트의 `docs/progress.html`로 복사합니다.
2. 파일 내부의 `<script id="data" type="application/json">` 블록을 프로젝트에 맞게 채웁니다.
3. 복사한 HTML 파일을 브라우저에서 엽니다.

기본 템플릿에는 업무가 등록되어 있지 않습니다. 먼저 JSON에 단계와 업무를 추가해야 보드와 캘린더에서 사용할 수 있습니다. 화면에서 새 업무를 생성하는 기능은 없습니다.

### 프로젝트 데이터 예시

```json
{
  "project": "나의 프로젝트",
  "subtitle": "개발 진행 상황과 업무 일정",
  "updated": "2026-11-04",
  "phases": [
    {
      "title": "1. 기획",
      "description": "요구사항과 개발 범위 정리",
      "tasks": [
        {
          "id": "plan-scope",
          "text": "개발 범위 확정",
          "done": true
        },
        {
          "id": "plan-wireframe",
          "text": "화면 흐름 스케치",
          "note": "핵심 화면의 와이어프레임 작성",
          "date": "2026-11-06"
        }
      ]
    }
  ]
}
```

| 항목 | 설명 |
| --- | --- |
| `project` | 프로젝트 이름이자 브라우저 저장 키의 기준입니다. 프로젝트마다 다르게 지정하고 사용 중에는 유지합니다. |
| `subtitle` | 프로젝트 설명입니다. |
| `updated` | 파일의 데이터 갱신일입니다. 체크나 일정 등록으로 자동 변경되지 않습니다. |
| `phases` | 단계 목록입니다. 각 단계에 `title`, 선택 항목인 `description`, 업무 목록인 `tasks`를 넣습니다. |
| `id` | 페이지 안에서 고유한 업무 ID입니다. 저장된 체크·날짜와 연결되므로 기존 업무의 ID를 유지합니다. |
| `text` | 업무 이름입니다. |
| `done` | 기본 완료 상태입니다. 생략하면 미완료이며, 브라우저에 저장된 체크 상태가 우선합니다. |
| `note` | 선택 항목인 업무 메모입니다. |
| `date` | 선택 항목인 기본 등록 날짜입니다. `YYYY-MM-DD` 형식이며, 브라우저에서 지정한 날짜가 우선합니다. |

JSON 문자열에 HTML 스크립트 종료 태그가 들어가지 않도록 합니다. 일정이 없는 업무는 `date`를 생략해도 됩니다.

## 업무 캘린더 사용법

1. 캘린더에서 원하는 날짜를 누릅니다.
2. **등록할 업무**에서 기존 업무를 선택합니다.
3. **등록 날짜**를 확인하고 **선택한 날짜에 등록**을 누릅니다.
4. 선택한 날짜 아래의 업무 목록에서 완료 체크하거나 **해제**를 누릅니다.

보드의 **+ 날짜 등록** 또는 이미 표시된 날짜를 눌러도 캘린더 등록 영역으로 이동합니다.

- **날짜 변경**: 같은 업무를 다른 날짜에 다시 등록합니다. 업무당 날짜 하나를 지정할 수 있습니다.
- **여러 업무 등록**: 같은 날짜에 여러 업무를 등록할 수 있습니다.
- **등록 해제**: 날짜 연결만 지웁니다. 업무와 완료 상태는 유지됩니다. JSON에 기본 날짜가 있더라도 브라우저에서 해제한 상태가 우선합니다.
- **월 이동**: 이전 달·다음 달 버튼을 사용합니다. **오늘**을 누르면 오늘 날짜가 선택됩니다.
- **체크 초기화**: 완료 체크만 JSON의 기본값으로 되돌립니다. 등록한 날짜는 유지됩니다.

## Claude Code 스킬로 사용하기

GitHub에 올린 실제 저장소 주소로 아래 URL을 바꿔 복제합니다.

```powershell
git clone https://github.com/<아이디>/progress-tracker.git "$HOME\progress-tracker"
```

Windows PowerShell에서 스킬 폴더를 연결합니다. 아래 명령은 해당 이름의 스킬 연결이 아직 없는 경우에 사용합니다.

```powershell
New-Item -ItemType Directory -Force -Path "$HOME\.claude\skills"
New-Item -ItemType Junction -Path "$HOME\.claude\skills\progress-tracker" -Target "$HOME\progress-tracker\progress-tracker"
```

프로젝트에서 다음처럼 요청합니다.

> 이 프로젝트를 분석해서 진행 체크 페이지 만들어줘.

스킬은 프로젝트의 README, 문서, 기존 TODO와 코드를 확인해 기본 위치인 `docs/progress.html`에 페이지를 생성하거나 기존 페이지의 데이터를 갱신하도록 구성되어 있습니다.

> 현재 코드 기준으로 진행 상황 갱신해줘. 기존 업무 ID는 유지해줘.

캘린더는 생성된 HTML에서 직접 날짜를 등록해 사용하면 됩니다.

## 저장 방식과 템플릿 업데이트

- 체크 상태와 등록 날짜는 브라우저의 `localStorage`에 저장됩니다. 저장을 사용할 수 없으면 화면에 안내가 표시됩니다.
- 브라우저에서 한 변경은 HTML 파일이나 GitHub에 자동 반영되지 않으며, 다른 PC·브라우저와 동기화되지 않습니다.
- 브라우저 데이터를 삭제하면 저장한 체크와 날짜 연결이 사라집니다. 파일 위치나 접속 주소가 바뀌면 기존 저장 상태를 불러오지 못할 수 있습니다.
- 다른 환경에서도 같은 기본 상태로 열려면 HTML의 JSON에 `done`과 `date`를 기록해 파일을 공유합니다.
- 공통 저장소에서 `git pull`하면 원본 템플릿과 연결된 스킬이 갱신됩니다. 이미 각 프로젝트에 복사한 HTML에는 자동 반영되지 않습니다.
- 기존 페이지에 새 디자인·기능을 적용하려면 프로젝트의 JSON과 업무 ID를 보존한 채 최신 템플릿으로 옮겨야 합니다.
